# OctoGraphicsBETA by Silentverge

(WIP) A DLL mod that adds extra graphic and post processing effects to OctoWoW like, HBAO, SMAA, DOF, Dynamic Shadows, Context Shadows, God Rays, Water Reflections and new fog, height and dynamic fog and lighting effects.
